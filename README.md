# -TahtaCep-
TahtaCep™; öğretmenlerin akıllı tahtayı telefon veya tablet üzerinden kullanmasını, öğrencilerin ise ders programı hazırlamasını ve 5–8. sınıf konularını çalışmasını amaçlayan bir eğitim platformudur. LGS hazırlığı ve OkulKahvehanesi ile öğrenmeyi daha düzenli ve etkileşimli hâle getirir.
